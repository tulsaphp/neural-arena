# NEURAL ARENA — AI Engineering Championship

A multiplayer browser game where players compete in AI-inspired strategy challenges. Built with HTML, CSS, JavaScript, and Supabase.

This is an educational software engineering project that demonstrates browser-based game development, multiplayer rooms, database integration, and server-side scoring. It does not train a neural network and does not require a paid AI API.

## Features

* Multiplayer rooms for 2–4 players.
* Six-character room codes.
* Anonymous player sessions through Supabase.
* Three rounds of AI and machine-learning-inspired challenges.
* Live room updates using Supabase.
* Server-side game logic and scoring through SQL functions.
* Responsive browser interface.
* Free static hosting through GitHub Pages.

## Game Rules

### Round 1 — Train the Brain

Choose a model for a small sensor dataset.

* Threshold classifier: 100 points.
* Nearest-neighbor: 70 points.
* Random guessing: 30 points.

### Round 2 — Debug the Machine

Identify the correct solution to a data-leakage problem.

* Fit preprocessing on training data only: 100 points.
* Other choices: 0 points.

### Round 3 — Agent Battle

Choose Scout, Harvester, or Optimizer.

A seeded simulation awards between 64 and 98 points depending on the arena conditions and selected strategy.
